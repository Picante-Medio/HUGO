## Generación de proyectos y compilación

### Generar proyecto

Si exclusivamente se quiere generar la solución y proyecto de visual estudio se debe ejecutar `build_solution.bat`. La solución estará disponible en la ruta `./HUGO/build/Windows/x64/`.

### Generar y compilar

Si se quiere compilar (que también refrescará el proyecto de visual studio) se debe ejecutar `compile_release.bat` (o `compile_debug.bat`). Los binarios generados estarán disponibles en la ruta `./HUGO/bin/`.

### Limpiar proyecto

Para limpiar los ficheros de proyecto y binarios generados será necesario ejecutar `./clean_build.bat`.
